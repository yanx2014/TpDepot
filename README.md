# TpDepot

## lead-url-lens-extension

The **TechNFirms Lead URL Lens** Chrome extension (Manifest V3). It captures LinkedIn
search results into a CRM, runs durable per-contact enrichment, and — via the new
**Feed** tab — analyzes a list of LinkedIn profiles against an ICP definition and
exports an enriched CSV (ICP score, persona card, opportunity score, and three
outreach messages per profile).

See [`lead-url-lens-extension/README.md`](lead-url-lens-extension/README.md) for the
Feed workflow and install steps. Load it via `chrome://extensions` → Developer mode →
**Load unpacked** → select the `lead-url-lens-extension` folder.
